PASSO A PASSO PARA RODAR O SITE
 1. Criar a pasta do projeto
No seu computador, clique com o botão direito
Crie uma nova pasta
 nome: projeto-site
 2. Criar os arquivos

Dentro da pasta:

 Arquivo 1:
Nome: site.html
 Arquivo 2:
Nome: style.css
 3. Colar os códigos

 Abra o site.html
Cole todo o código HTML que te mandei

 Abra o style.css
Cole o código CSS

 4. Conectar HTML com CSS

Isso já está no HTML, mas confira se tem isso:

<link rel="stylesheet" href="style.css">
 5. Rodar o site

 Agora vem a parte fácil:

Clique duas vezes no arquivo site.html
OU
Clique com botão direito → “Abrir com navegador”

✔ Pode ser:

Google Chrome
Edge
Firefox
